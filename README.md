# RunComfy

RunComfy AI is a running route recommendation app for Switzerland.

## Features

- Personalized running distance
- Fitness level selection
- Real running routes
- Current temperature
- Air quality
- Interactive route map

## Technologies

- Python
- Streamlit
- OpenRouteService API
- Open-Meteo API
- Folium

## Goal

Help runners find comfortable running routes based on
their fitness level and environmental conditions.

## Future features

- Elevation analysis
- Shade estimation
- Personalized route scoring
